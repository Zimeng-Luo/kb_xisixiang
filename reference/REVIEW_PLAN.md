## 3. 分配原则
1. 类别主责优先；同类别内尽量让同一知识节点下的材料由同一人审阅，保持上下文连贯。
2. 每项唯一归属一位「主审」，避免重复劳动；图片作并行支线摊给全员。
3. 节点评审是总纲：先审节点确定主题与结构，再让材料审阅（文档/图片/试题）以其所属节点为上下文。

## 4. 审阅结论分级
- **pass**：通过，无需修改
- **pass_with_changes**：需修改但不影响整体可用（附建议）
- **reject**：存在严重问题（事实/政治表述/命题错误）需返工

## 5. 回填修改方向
汇总各条结论后，依据结论调用 `data_function/updata.py`：
- 修改内容：`update_node_content` / `create` 重建材料
- 状态推进：验收通过项由 `draft` → `reviewed`（乃至 `published`）
