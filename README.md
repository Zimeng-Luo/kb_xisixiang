
## 一、知识库基本信息

本知识库以《习近平新时代中国特色社会主义思想学习纲要》为权威文本来源，将教材内容结构化、图谱化、可评估化，形成一套「知识节点 — 材料文档 — 题库」三位一体**的结构化知识体系。

### 1.1 内容规模

| 类别 | 数量 | 说明 |
|---|---|---|
| 知识节点 nodes | **197** | 覆盖导论、第 1~17 章、补充模块、专名补充 |
| 材料文档 documents | **1182** | 原文要义、概念解析、实践意义、案例等 |
| 客观试题 test | **920** | 单选 683 + 判断 237，全部为客观题 |
| 依赖边 edges/dependence | **385** | 知识点前置/依赖关系（best-effort 重建） |
| 其他边 edges/other | **67** | COMPOSES/APPLIES/RESEMBLES/CONTRASTS 关系 |
| 数据模式 schemas | **7** | node/document/picture/test/dependence/other/manifest |
| 索引 indexes | **11** | 节点索引与各类边入/出索引 |
| 质量评估报告 report | **2300** | 197 节点 + 1182 文档 + 920 试题的质量评估 |

## 二、构建过程

### 2.1 从原始教材到结构化知识库


1. **文本来源**：以《习近平新时代中国特色社会主义思想学习纲要》各章原文为底本，综合融入提纲、教案以及丰富的网络案例。

2. **知识点切分**：按教材章节与核心论断，将全文切分为 **197 个知识节点**，为每个节点提炼 `name`（主题）、`abstract`（实质概括）、`difficulty`、`importance`、`keywords`、`tags`。

3. **材料挂接**：为每个节点关联**原文要义、概念解析/理论背景、实践意义与关联、现实案例**等文档，形成 `documents` 引用。

4. **命题生成**：为每个节点配套**客观题**（单选/判断），累计 **920 道**，均含题干、选项、答案与解析。

5. **图谱构建**：生成节点间的**前置依赖边**（`dependence`，含依赖强度 requirement）与**组成/应用/相似/对比边**（`other`），并据此重建索引。

6. **模式规范**：定义 7 个 JSON Schema，统一节点/文档/图片/试题/边的数据结构。

  
### 2.2 质量审阅与修复

- **全量筛查**：对结构完整性、引用一致性、映射一致性做全量校验，确认节点→文档、节点→试题引用 0 缺失，边引用 0 落空。

- **AI内容审阅**：完成基本的构建后，利用AI对整体数据库进行整理核实，修正明显质量问题。

- **AI质量评估报告**：利用当前业内领先LLM模型，对知识库内容逐一筛查，建立质量分析报告。

- **人工审核**：召集优秀学生，借助质量分析报告，对知识点进行逐一审查，并逐一搜集修正意见。

- **再次优化**：根据质量评估报告、人工审阅意见，对存在微小瑕疵的420条数据进行修正，确保结果严谨。

## 三、可使用的领域

### 3.1 教育教学（思政与理论武装）

- 高校思政课、党校/干部培训、理论学习的**结构化教材**。

- 按章节与知识节点检索、讲解、备课，提供**原文要义 + 概念解析 + 现实案例**的完整学习素材。
  
### 3.2 试题命制与测评

- 内置 **920 道客观题**（单选+判断），含答案与解析，可直接用于：

  - 随堂测验、章节练习、阶段考核；

  - 依节点难度与考纲筛选组卷；

  - 作为后续开发**主观题/材料分析题**与试题答客观化的基础。

### 3.3 知识图谱与检索增强（RAG）

- 197 节点 + 385 依赖边 + 67 关系边构成**可导航的知识图谱**，支持：

  - 前置知识溯源（学某概念需先掌握什么）；

  - 概念关联检索（相似/组成/应用/对比）；

  - 结合本知识库做**检索增强生成（RAG）**，回答基于权威文本的问答。

### 3.4 内容质量与合规审阅

- 每项目均有**质量评估报告**（准确性/完整性/规范性/结构/一致性/命题与答案等维度），可用于：

  - **人工终审与修订**（按「必须修改项」定位问题）；

  - 内容合规自查（政治表述、史实、概念一致性）。

### 3.5 政务党建与宣传教育

- 理论学习平台、融媒体宣传的**权威内容底座**。

- 面向基层、校园、机关的理论宣讲与知识问答。

## 四、具体价值
  
### 4.1 结构化的权威知识资产

- 以**权威教材原文**为唯一真实来源，杜绝生造与错漏；节点、文档、试题、边四类实体被 schema 规范化，可机器读、可校验、可演进。
  
### 4.2 一课一查、一键成题的效率提升

- 从"翻书找段落"变为"按知识节点直达原文要义与案例"；

- 920 道客观题**现成可用**，显著降低命题与出题成本。

### 4.3 可解释的知识关联

- 依赖边明确"学什么前置什么"，其他边明确概念间**组成/应用/相似/对比**关系，为个性化学习路径、智能答疑、图谱问答提供结构支撑。

### 4.4 可审计、可持续的质量机制

- 2300 份质量评估报告 + 完善的 schema + manifest 版本管理，构成**可审计、可迭代**的质量闭环；修订有依据、版本可追溯。

- 即使数据源变更或误删，也可依据成熟的 schema、映射与评估机制**快速重建与再校验**。

### 4.5 多端复用与生态扩展

- 纯 JSON + Schema 的结构天然适配**Web 展示、检索系统、大模型 RAG、移动端**等多种载体；

- 提供 `知识库本地审阅系统` / `RAG审核` 等配套网页，便于在线审阅与成果复用。
