# 主观题 → 客观题 转换规则（test 与 node 同步）

## 任务目标
把 `materials/test/下的主观题` 全部转换为客观题（判断题或单选题），**保留原题所考察的知识点要求**，
并**同步更新** `nodes/` 下对应节点的 `test` 数组条目（style 与 description）。

## 判定：哪些文件算“主观题”需要转换
- 题目要求书面作答、按得分点评分、没有固定唯一正确答案的均属主观题。
- 典型类型：概念简答、简答、论述、应用分析、材料分析、综合、比较分析、关联分析、
  辨析判断（“判断并说明理由”属于主观）等。
- 少数文件已是客观题式（题干带 A/B/C/D 选项的单选题，如 test_812、test_900；或纯填空题），
  **若已可视为客观题则只需轻量规范化**，不要照实再从简答改写。是否客观看“是否有确定的唯一正确答案”。

> 注意：即使字段叫“辨析判断”或 title 含“选择”，只要它要求书面说明理由、答案不唯一，
> 都按主观题处理并转换为标准的判断题或单选题（每条只给一条题干文本）。

## 目标文件格式（test）
严格保持 schema 字段与顺序（schema_version, revision, status, updated_at, test_id, title, item, requirement）。
```
{
  "schema_version": "1.0",
  "revision": 1,
  "status": "published",
  "updated_at": "2026-08-11T00:00:00Z",
  "test_id": "<原test_id不变>",
  "title": "判断题"  或  "单选题",
  "item": [ "<仅一条题干文本>" ],
  "requirement": [ "<答案行>", "<知识点依据…>", ... ]
}
```
- `item` 必须是**恰好 1 个元素**的数组。
- **判断题**：item[0] 为一句确定性陈述（“判断下列说法是否正确：……” 或直接给判断句）。
  requirement[0] 形如 `"答案：正确"` 或 `"答案：错误"`，之后列出该知识点依据（可合并/精炼原得分点）。
- **单选题**：item[0] 为“题干 + A/B/C/D 四个选项”，如：
  `关于……，下列说法正确的是（ ）：A.…… B.…… C.…… D.……`
  requirement[0] 形如 `"答案：B"`；之后为知识点依据（含对其他干扰项的排除理由，若必要）。
- 知识点依据要忠实反映原 `requirement` / 原题干考察的知识点（“保留知识点要求”），
  但语言可在客观题框架内重写；正确答案必须与原文献/知识一致。

## 节点同步更新（node)
每个 test 都唯一挂在某个节点的 `test` 数组。
读取 `_test2node.tsv`（或任务清单）里 test 对应的 nodeFile 与 style/description。
转换该测试后，把节点对应 `test` 条目改为：
- `test_id`：不变
- `style`：改为 `"判断题"` 或 `"单选题"`
- `description`：改为与 test 的 item[0] 相同/等效的题干文本
其余字段（documents、pictures、assessment 等）一律不动，只改该条 test 的 style 与 description。

## 题型选择
- 原题是判断正误类（辨析判断、是非辨析、判断并说明理由、观点评析）→ 优先转 **判断题**。
- 原题是概念简答、简答、论述、应用分析、材料分析、综合、比较、关联等 → 转 **单选题**（A/B/C/D）。
- 若某知识点天然只有对/错两种可能 → 判断；若涉及多选知识点联想 → 单选题。
- 每题只保留**单一确定答案**。

## 质量要求
- 必须保持原文政治立场与表述严谨，不得歪曲原知识点。
- 干扰项要有迷惑性但明确错误，与正确项同质、不互相包含。
- item 保持一句完整、自包含的题干；不要把得分点当作题干。
- 输出能通过 `schemas/test_material.schema.json` 与 `schemas/node.schema.json`（node_test_ref）校验：
  - 无多余字段；item/requirement 为非空字符串数组；style/description 为非空字符串。
- 每个文件转换后**务必直接写回磁盘**（test 文件与 node 文件），保持 UTF-8、原缩进风格（2 空格）。

## 参考范例
### 范例 1（单选题）—— test_803 → 单选题
原：概念简答「中国特色社会主义是历史和人民的选择而非凭空构想」，得分点：历史课题、方案失败/中共应运而生、历史逻辑与理论逻辑、接续巩固动态检验。
转为：
```
{
  "schema_version": "1.0", "revision": 1, "status": "published", "updated_at": "2026-08-11T00:00:00Z",
  "test_id": "test_803", "title": "单选题",
  "item": ["关于'中国特色社会主义是历史和人民的选择'这一判断的形成逻辑，下列说法正确的是（　）：A.它是少数人凭主观构想设计出来的结果。 B.它是近代中国历史演进与社会矛盾运动的产物，是历史逻辑与理论逻辑相统一的结果。 C.它是照搬西方现代化模式的产物。 D.它一经选定就固定不变、无需再接受实践检验。"],
  "requirement": [
    "答案：B",
    "必须解决民族独立、人民解放与国家富强、人民幸福的历史性课题，是历史逻辑的体现",
    "马克思主义基本原理同中国实际相结合，中国共产党应运而生，体现理论逻辑",
    "在新民主主义革命、社会主义革命建设和改革开放中接续巩固，并接受实践的动态检验"
  ]
}
```
对应 node（node_0101）test_803 条目：
```
{ "test_id": "test_803", "style": "单选题", "description": "关于'中国特色社会主义是历史和人民的选择'这一判断的形成逻辑，下列说法正确的是（　）：A.它是少数人凭主观构想设计出来的结果。 B.它是近代中国历史演进与社会矛盾运动的产物，是历史逻辑与理论逻辑相统一的结果。 C.它是照搬西方现代化模式的产物。 D.它一经选定就固定不变、无需再接受实践检验。" }
```

### 范例 2（判断题）—— test_904 → 判断题
原：辨析判断"强调党是最高政治领导力量会导致党包办代替国家机关职能"。
转为：
```
{
  "schema_version": "1.0", "revision": 1, "status": "published", "updated_at": "2026-08-11T00:00:00Z",
  "test_id": "test_904", "title": "判断题",
  "item": ["判断下列说法是否正确：坚持党的全面领导，就是由党包办代替国家机关的全部职能。"],
  "requirement": [
    "答案：错误",
    "党的全面领导是总揽全局、协调各方，支持和保证各国家机关依法各司其职、各负其责，而非事事包办代替",
    "正是在党的领导下，各机关才既充分发扬民主又实行有效集中、形成统一高效的整体",
    "党的领导是方向、章法、力量的保证，不是事无巨细地干预国家机关的具体职能"
  ]
}
```
对应 node（node_0304）的 test_904 条目 style 改为 "判断题"，description 设为上例 item[0]。
